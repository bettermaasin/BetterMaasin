# BetterMaasin

![BetterMaasin](https://ghrb.waren.build/banner?header=BetterMaasin&subheader=A+community-run+portal+for+Maasin+City&font=Figtree&bg=0066eb&color=fff&subcolor=e6f0fd&support=true)

A community-run portal for **BetterMaasin.org** — a better, more usable and citizen-friendly website for Maasin City.

We aim to make local government services, information, hotlines, tourism, and statistics easy to find and understand — for every Maasinhon.

**Demo site:** https://bettermaasin.netlify.app

## Tech Stack
React · Vite · Tailwind CSS

## Getting Started
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Build
```bash
npm run build
npm run preview
```
